# Olist E-commerce Analysis

## Project Overview
This project analyzes e-commerce order performance, delivery efficiency and customer behavior using Python, SQL and Power BI.

## Tools
- Python (Pandas)
- SQL
- Power BI
- Logistic Regression

## Key Analysis
- GMV and AOV analysis
- Delivery funnel analysis
- Daily GMV trend analysis
- Regional sales analysis
